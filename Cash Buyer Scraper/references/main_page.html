Welcome to the Bergen County Clerk's Land Records Public Search Page. This site contains public documents, including deeds and mortgages, recorded into the Official Records of Bergen County, New Jersey from January 1, 1970 to present.


The advanced search is currently compatible with Microsoft Edge, Mozilla Firefox or Google Chrome. Chrome users must also have the ClickOnce extension which can be found by clicking here. Firefox users must have the Breez Clickonce extension which can be found by clicking here.
        

If you are not using the above browser, please use the basic search below.
